# Imperial Projects

Selected coursework projects from my time at Imperial College London. Each project is self-contained, with its own setup, docs, and tests.

## 📋 Projects

| Year / Term | Project                                                                | Stack              | Description                                                                       |
| ----------- | ---------------------------------------------------------------------- | ------------------ | --------------------------------------------------------------------------------- |
| Y2 T3       | [Keep Playing](y2-t3_keep-playing/)                                    | Django + Flutter   | Sports coaching platform connecting event organisers with coaches and referees    |
| Y3 T1       | [Choose Your Own Adventure](y3-t1_choose-your-own-adventure/)          | FastAPI + React    | LLM-powered interactive story / gamebook generator with a graph-based editor     |

## 🚀 Getting Started

Each project has its own README at its root — start there for setup, demo accounts, and configuration. Both projects run via Docker Compose.

- [`y2-t3_keep-playing/README.md`](y2-t3_keep-playing/README.md)
- [`y3-t1_choose-your-own-adventure/README.md`](y3-t1_choose-your-own-adventure/README.md)

## 🗂 Repository Layout

```text
imperial_projects/
├── y2-t3_keep-playing/                # Year 2, Term 3 — sports coaching platform
└── y3-t1_choose-your-own-adventure/   # Year 3, Term 1 — LLM gamebook generator
```

The `yN-tM_...` directory naming reflects the Imperial academic year (`Y`) and term (`T`) in which the project was completed.
